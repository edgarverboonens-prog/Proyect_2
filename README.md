📚 Estructuras de Datos y Algoritmos de OrdenamientoEste repositorio contiene la implementación técnica de estructuras de datos lineales y algoritmos de ordenamiento fundamentales, utilizando tanto tipos de datos básicos como estructuras personalizadas (Objetos/Structs).🛠️ Estructuras de Datos ImplementadasCada estructura admite tipos de datos simples (int, char) y Tipos de Datos Definidos por el Usuario (TDA), como una clase Usuario o Producto.1. Pilas (Stacks)Principio: LIFO (Last In, First Out).Métodos principales: push(), pop(), peek().Uso: Gestión de llamadas en memoria (Stack Trace) y reversión de procesos.2. Colas (Queues)Principio: FIFO (First In, First Out).Métodos principales: enqueue(), dequeue(), front().Uso: Sistemas de turnos, procesamiento de tareas en segundo plano.3. Listas Enlazadas (Linked Lists)Tipo: Simplemente enlazadas / Doblemente enlazadas.Ventaja: Inserción y eliminación dinámica sin reasignar todo el array.Dato Personalizado: Implementación capaz de almacenar nodos con múltiples atributos.⚡ Algoritmos de OrdenamientoSe incluyen comparativas de eficiencia para diferentes volúmenes de datos.🔵 Ordenamiento Burbuja (Bubble Sort)El método más sencillo pero menos eficiente para grandes volúmenes.Complejidad: $O(n^2)$Lógica: Compara elementos adyacentes y los intercambia si están en el orden incorrecto.🟢 Merge Sort (Ordenamiento por Mezcla)Algoritmo basado en la técnica "Divide y Vencerás".Complejidad: $O(n \log n)$Lógica: Divide el arreglo en mitades recursivamente, las ordena y luego las combina. Es altamente estable.🔴 Quick Sort (Ordenamiento Rápido)Generalmente el más veloz en la práctica.Complejidad: $O(n \log n)$ promedio.Lógica: Selecciona un "pivote" y particiona los demás elementos en dos subgrupos (menores y mayores al pivote).📋 Ejemplo de Estructura de Dato PersonalizadoPara demostrar la versatilidad, las estructuras no solo guardan enteros, sino objetos complejos:JSON{
  "id": "uuid",
  "nombre": "String",
  "prioridad": "int",
  "fecha_creacion": "DateTime"
}
